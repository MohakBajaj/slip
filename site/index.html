__FAQ_PRICE__

is jot only for macos?

yes. jot is a macos app.

which permissions does jot ask for?
  • accessibility. jot captures a selection, and pastes dictated text into the app in front.
  • input monitoring. the fn hold works while another app is in front.
  • microphone. jot hears you dictate.
  • screen recording. jot captures the screen when you annotate.
where does my data live?

every jot is a markdown file at ~/Documents/Jot/, named YYYY-MM-DD-id.md. no account, no sync, no telemetry. agents and other tools can read the folder. parakeet, and cleanup with apple's on-device model, stay on the machine. pick a cloud model, and that part is sent to the model you chose.
